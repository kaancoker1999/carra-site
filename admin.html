Admin accounts

Each admin signs in with their name and a password, and can only change what is ticked for them. The password you set here is a starting password: at their first sign-in they must choose their own, which you never see. Everyone can see customers, orders, payments and messages. Passwords are not stored in readable form, so they can't be shown again — set a new one if someone forgets theirs.
